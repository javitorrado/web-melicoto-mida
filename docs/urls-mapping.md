## 4. Estructura de fitxes de producte

**Pattern confirmada (escanejada):**
```
/productes/<categoria>/<subcategoria>/<slug-producte>/
```

**Exemples reals escanejats:**
1. Camiseta "Rissaga": `/productes/textil/camisetes/camiseta-rissaga/` (22.90€)
2. Camiseta "Pauma": `/productes/textil/camisetes/camiseta-pauma/` (24.90€)
3. Camiseta "Bous de Costitx": `/productes/textil/camisetes/camiseta-bous-de-costitx/` (22.90€)
4. Camiseta "Si sa curtor fos boira": `/productes/textil/camisetes/camiseta-si-sa-curtor-fos-boira/` (19.90€)

### Variants de producte (talla/color)

Cada producte ofereix **variants per talla**:
- Talles adultes unisex: XXS, XS, S, M, L, XL, XXL, XXXL
- Els productes indiquen "diverses variants" disponibles
- Cada talla té una gestió d'estoc independent a WooCommerce

**Estructura de dada estimada (WooCommerce):**
- Producte pare (variable product)
- Variants fill (cada talla és una variant)
- Preu unificat per talla (o potser diferenciat per talla — a verificar)
- Estoc per cada talla

### Etiquetes de producte

Els productes estan etiquetats amb múltiples tags:
- Exemple: Camiseta "Rissaga" té tags "Estiu" i "Estiu 2026"
- Els tags són accessibles via URL `/shop/etiqueta-producte/<slug>/`

## 8. Notes de descoberta

- **Tasses:** subcategoria duplicada entre Ca nostra i Cuina. WooCommerce permet productes en múltiples categories.
- **Etiquetes:** ha descobert ~30+ tags temàtiques. Totes accessibles via `/shop/etiqueta-producte/<slug>/`.
- **Variants de producte:** confirmades talles (XXS-XXXL). Estructura WooCommerce: producte pare + variants fill.
- **Enviament:** "Envío certificat gratuito a partir de 60€" mencionat a les fitxes (2-5 dies laborals).
- **Moneda:** tots els preus en €. IVA inclòs.
- **Composició de material:** documentada a fitxes (ex. "100% algodó orgànic").
- **Taules de mesures:** disponibles a les fitxes de producte per talla.
